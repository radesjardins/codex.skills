# Creative Unblocking

Use this reference when the user has no starting ideas, repeats one direction, or cannot answer a broad prompt. Keep the entry small. A blank page often reflects an unclear problem, fear of choosing too early, missing context, or a prompt that is too broad.

## Progressive engagement ladder

Move one step at a time. Stop as soon as the user begins to generate useful material.

1. Ask what happened or what feels wrong.
2. Identify who is affected and what they need.
3. Ask what has already been tried or ruled out.
4. Name one hard constraint.
5. Use one short warm-up from `methodology-catalog.md`.
6. Turn the strongest observation into a How Might We question.
7. Begin normal idea generation.

## Small interventions

| Symptom | Intervention |
| --- | --- |
| "I have no idea" | Ask for the most recent event that caused the concern. |
| The topic is too broad | Ask which person or outcome matters first. |
| The user fears a bad first answer | Ask for a deliberately weak or incomplete attempt. |
| One idea keeps returning | Use reverse brainstorming or an analogy from another field. |
| Constraints block every answer | Ask which constraint is fixed and which is only assumed. |
| The user wants examples | Switch to generator mode and label every AI idea. |

## Warm-up choices

- **Worst Possible Idea:** Use for perfectionism or low energy. Generate bad answers, then extract one useful principle.
- **Crazy 8s:** Use when speed will reduce overthinking. Ask for eight short ideas and avoid discussion until the list is complete.
- **Random Entry:** Use when the current idea family is narrow. Pick one unrelated noun, list its useful traits, and connect one trait to the problem.
- **Starbursting:** Use when the problem is unclear. Generate questions before answers.

Read the matching card in `methodology-catalog.md` only when more detail is needed.

## Generator mode

Use generator mode when the user asks to react to AI ideas or still has no usable idea after the ladder. State that AI will supply the first anchors. Offer a small varied set, label each idea `[AI]`, and ask the user to reject, combine, or rewrite them.

## Stop conditions

Leave unblocking mode when one of these is true:

- the user has two useful directions;
- one clear How Might We question exists;
- the user can name a desired result and hard constraint;
- the user asks to pause or switch tasks.
